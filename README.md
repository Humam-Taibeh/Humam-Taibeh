## About Me

I'm a third-year **B.Sc. Artificial Intelligence** student at **Al-Zaytoonah University of Jordan** (Class of 2028), based in Amman. I build complete, working software, mostly tools I actually use myself, taking each one from an idea to something people can install and run. I'm looking for a technical internship where I can keep learning.

### How I work (full transparency)

**AI coding tools write almost all of the code in my projects**, and I say so openly. My part is everything around it: deciding what to build, defining the architecture, data contracts and safety constraints, writing the specifications and prompts, then testing and refining until it works.

I'm not trying to "generate and ship" blindly. I'm learning how to use AI the right way: clear requirements, small steps and iteration. My workflow lives entirely inside **Claude Code in VS Code**, and I'm actively studying **prompt engineering** to do it more deliberately. Alongside that, I'm building my own programming fundamentals in Python and SQL.
