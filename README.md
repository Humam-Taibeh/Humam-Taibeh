## 🧭 About Me

I'm a 3rd-year **B.Sc. Artificial Intelligence** student at **Al-Zaytoonah University of Jordan** (Class of 2028), based in Amman. I'm still a student, still learning, and I like being upfront about how I work.

**AI coding tools write almost all of the code in my projects.** My part is everything around it: deciding what to build, defining the architecture, data contracts and safety constraints, writing the specs and prompts, then testing and refining until it works.

I'm not trying to "generate and ship" blindly. I'm learning how to use AI the right way: clear requirements, small steps, and iteration. My workflow now lives entirely inside **Claude Code in VS Code**, and I'm actively studying **prompt engineering** to do it more deliberately.
