## 🧭 نبذة عني

أنا طالب في السنة الثالثة في تخصص **الذكاء الاصطناعي (B.Sc.)** في **جامعة الزيتونة الأردنية** (دفعة 2028)، ومقيم في عمّان. ما زلت طالباً وما زلت أتعلّم، وأفضّل أن أكون واضحاً بخصوص طريقة عملي.

**أدوات البرمجة بالذكاء الاصطناعي هي التي تكتب تقريباً كل الكود في مشاريعي.** دوري هو كل ما حوله: تحديد ما سأبنيه، وتصميم البنية وعقود البيانات وقيود الأمان، وكتابة المتطلبات والـ prompts، ثم الاختبار والتحسين المتكرر حتى يعمل المشروع كما يجب.

لا أحاول أن "أولّد الكود وأنشره" بشكل عشوائي. أتعلّم كيف أستخدم الذكاء الاصطناعي بالشكل الصحيح: متطلبات واضحة، خطوات صغيرة، وتحسين متواصل. أصبح عملي الآن بالكامل داخل **Claude Code في VS Code**، وأدرس **هندسة الـ prompts (Prompt Engineering)** لأستخدمه بشكل أكثر وعياً.

## 🚀 أبرز المشاريع

| 🔔 **[UniNotifier](https://github.com/Humam-Taibeh/UniNotifier)** | يعمل على جهاز Windows الخاص بي، ويراقب Moodle الجامعة، ويرسل الملفات الجديدة والواجبات والمواعيد النهائية وتنبيهات المحاضرات والعلامات إلى بوت Telegram خاص. تُحفظ ملفات المساقات تلقائياً مع مخطط للمعدل التراكمي. بدون خادم وبدون اشتراك، وبيانات الدخول تبقى على الجهاز. | Python · Playwright · Telegram Bot API · Windows Task Scheduler · PowerShell |

| 🚀 **[Rise](https://github.com/Humam-Taibeh/Rise)** | تطبيق لإدارة المهام وسير العمل مع تحديث لحظي للبيانات عبر Supabase. | React · Vite · Supabase (PostgreSQL) |

## 🧪 ما تتضمنه مشاريعي

* **مشاكل حقيقية:** أدوات بنيتها لأني احتجتها (UniNotifier وDevCore).
* **الاختبارات:** اختبارات وحدة واختبارات شاملة (end-to-end) واختبارات تعمل بدون اتصال.
* **الأمان والخصوصية:** أمان على مستوى الصفوف (RLS)، وإخفاء الأسرار في السجلات، وبيانات دخول محلية فقط.
* **التوثيق:** ملفات README بالإنجليزية والعربية.
