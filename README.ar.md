## 🚀 أبرز المشاريع

### 🔔 [UniNotifier](https://github.com/Humam-Taibeh/UniNotifier)
**جامعتي على هاتفي، لحظة بلحظة.** خدمة تعمل في الخلفية على Windows، تراقب Moodle الجامعة وترسل كل ما يهم إلى بوت Telegram خاص بي. بدون خادم وبدون اشتراك، ولا يغادر الجهاز أي شيء سوى الرسائل المرسلة إلى بوتي.

* **مراقبة المساقات:** ملفات جديدة، واجبات، اختبارات، إعلانات، منشورات منتدى ومحاضرات Teams، كلٌّ منها كلقطة شاشة للعنصر أو الملف نفسه. وعند التعديل يظهر ما الذي تغيّر (*قبل* / *بعد*).
* **أرشفة تلقائية:** يُحفظ كل ملف داخل مجلد المساق في `01_Lectures` / `02_Assignments` / `03_Exams` دون تكرار. وإذا رفع المدرّس نسخة جديدة تحلّ محل القديمة التي تنتقل إلى `_Old_Versions`.
* **المواعيد والمحاضرات:** تذكير قبل 24 ساعة وقبل ساعة من الواجبات والاختبارات، وقائمة يومية بالمهام المفتوحة، وتنبيهات المحاضرات مع زر **Join**. والتحضير التلقائي اختياري.
* **العلامات والمعدل:** يكتشف العلامات المنشورة، ويجد صفّي داخل ملفات العلامات (Excel وWord وPDF) عبر الرقم الجامعي، مع حاسبة "العلامة المطلوبة" ومخطط للمعدل التراكمي.
* **أدوات الخطة الدراسية:** كشف العلامات والرصيد عند الطلب، وتقدّم الدرجة من خطتي الدراسية، و**خطة التسجيل** التي تقترح ما يُسجَّل في الفصل القادم بحسب المتطلبات السابقة وقواعد الساعات.
* **إدارة ذاتية:** البوت يعيد تشغيل نفسه، ويحوّل التحقق الثنائي من Microsoft إلى Telegram، ويكتشف الصيانة، ويقدّم تحديثاً بضغطة واحدة مع تراجع تلقائي إذا لم تعمل النسخة الجديدة.

<details>
<summary><b>تحت الغطاء</b></summary>

* **مهمتان مجدولتان في Windows:** `monitor.py` يفحص كل 15 دقيقة (عبر HTTP مع جلسة محفوظة، ولا يُستخدم Chromium بلا واجهة إلا لتسجيل الدخول ولقطات الشاشة). و`bot.py` يعمل دائماً، يردّ على الأوامر ويلقي نظرة خفيفة على Moodle كل دقيقتين.
* **تتبّع بالمقارنة:** كل فحص يُقارن بالحالة المحفوظة سابقاً، فلا يُعلَن إلا عن التغييرات الفعلية. والتشغيل الأول يسجّل الوضع الحالي بصمت.
* **Stale-while-revalidate** لبوابة التسجيل: يجيب فوراً من آخر نسخة محفوظة ويحدّثها في الخلفية.
* **الخصوصية والأمان:** بيانات الدخول في ملف `.env` غير متتبَّع بـ Git ومخفية في السجلات وتنبيهات الأخطاء، والبوت يخدم مالكاً واحداً فقط، وهناك اختبار يفشل إذا تتبّع Git أي ملف شخصي.
* **الجودة:** مجموعة اختبارات تعمل دون اتصال (أي اتصال خارجي يُفشل التشغيل)، وكود نظيف حسب pyflakes، وCI عبر GitHub Actions، وأداة تشخيص `doctor`، ومثبّت، وتوثيق بالإنجليزية والعربية.
</details>

**التقنيات:** Python · Playwright · Telegram Bot API · Windows Task Scheduler · PowerShell

### 📚 DevCore 🔒 *(مستودع خاص)*
**منهج ذاتي التعلّم لهندسة الـ Backend والذكاء الاصطناعي بالعربية (اللهجة الأردنية، RTL).** يحوّل خارطة طريق طويلة إلى 4 أقسام ← 21 وحدة ← أقسام فرعية بحجم أسبوع ← مهمة واحدة في كل مرة، فيعرف المتعلّم دائماً الخطوة التالية الوحيدة. يضم نحو 1,050 ساعة من المحتوى، ويُقاس التقدم بالنسبة المئوية دون مواعيد نهائية.

* **مهمة واحدة في كل مرة:** صفحة "اليوم" تعرض المهمة التالية فقط، ومشغّل دراسة يعرض خطوة واحدة مع مصطلحاتها الجديدة وقالب جاهز (README أو ADR أو مستند تصميم) عند الحاجة.
* **امتحانات مبنية على ما درسته:** امتحانات أسبوعية وللوحدات وللمصطلحات وللمراحل ونهائي، وامتحان الوحدة يُفتح عند إتمام 80% منها. واختبار تحديد المستوى (النجاح عند 85%) يتيح تخطّي الوحدات المعروفة مسبقاً.
* **شريك دراسة:** ملخص صغير للتقدم يُشارَك فقط مع شريك قَبِل الطلب.
* **PWA يعمل محلياً أولاً وقابل للتثبيت:** يُحفظ التقدم في المتصفح أولاً فيكون التطبيق فورياً ويعمل بدون إنترنت.
* **مزامنة سحابية:** عند تسجيل الدخول يتزامن التقدم بين الأجهزة لحظياً ويُدمج بأمان إذا تغيّر شيء على جهازين معاً. ولا تضيع أي خطوة منجَزة.

<details>
<summary><b>تحت الغطاء</b></summary>

* **محرك المزامنة:** كتابة بتحكّم تفاؤلي بالتزامن (`save_progress` RPC) لا تستبدل الحالة المخزّنة إلا إذا كان إصدار العميل ما زال الأحدث. عند التعارض يجلب النسخة السحابية ويدمجها (اتحاد الخطوات المنجَزة وأيام الدراسة، مع الاحتفاظ بأفضل نتيجة امتحان) ثم يعيد المحاولة. والتحديثات اللحظية من Supabase.
* **المخطِّط:** يوزّع ساعات كل شهر على أسابيع متوازنة (برمجة ديناميكية مع إصلاح محلي)، والخطة بلا تواريخ تقويمية.
* **الأمان:** أمان على مستوى الصفوف (RLS) في كل جدول، والحسابات الجديدة تحتاج موافقة مشرف (والدعوات تتجاوزها)، وتعديل العضويات والشراكات يتم فقط عبر دوال قاعدة بيانات تتحقق من المستخدم، ورفض البناء إذا وُضع مفتاح Supabase سري في متغير `VITE_*`، مع رؤوس CSP وHSTS وX-Frame-Options صارمة.
* **الاختبار:** اختبارات Vitest (سلامة المحتوى والحالة والمخطِّط ومحرك المزامنة ومخطط SQL على Postgres حقيقي عبر PGlite) واختبارات Playwright شاملة على سطح المكتب والجوال، مع ESLint وPrettier.
</details>

**التقنيات:** Vanilla JS · Vite · Supabase (Postgres, RLS) · Vitest · Playwright
